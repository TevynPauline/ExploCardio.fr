# Hébergement des données de santé

Les logiciels proposés par ExploCardio.fr fonctionnent sur une plateforme Cloud dédiée,
hébergée par notre partenaire dans un centre de données certifié Hébergeur de données de
santé (HDS). Vos données patients restent sur cette plateforme ; elles ne transitent jamais
par le site ExploCardio.fr.

Cette offre est **en préparation**. Pour être informé de son ouverture, contactez-nous.
