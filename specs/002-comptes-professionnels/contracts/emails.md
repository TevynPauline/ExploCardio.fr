# Emails de F02

Rendus avec le gabarit de la charte (F11), au vouvoiement, sans donnée de patient ni mot de
passe ; envoyés par le connecteur emailing (boîte de démonstration en phase 1).

| Modèle | Destinataire | Déclencheur |
|---|---|---|
| Confirmez votre adresse | Professionnel | Inscription, renvoi |
| Votre compte est validé | Professionnel | Validation (manuelle ou automatique) |
| Votre demande de compte | Professionnel | Refus (invitation à contacter l'équipe) |
| Votre compte est suspendu / rétabli | Professionnel | Suspension, rétablissement |
| Votre mot de passe a été modifié | Professionnel | Réinitialisation ou changement |
| Votre compte est temporairement bloqué | Professionnel | 5 échecs de connexion |
| Confirmez votre nouvelle adresse / Votre adresse a été changée | Nouvelle / ancienne adresse | Changement d'email |
| Double authentification activée / désactivée | Professionnel | Changement |
| Votre cadeau de bienvenue arrive bientôt | Professionnel | Cadeau en rupture |
| Votre compte a été supprimé | Professionnel | Suppression RGPD |
| Nouveau compte à valider | Équipe | Email confirmé (validation manuelle) |
| Réinscription d'un compte refusé | Équipe | Cas limite |
| Changement de numéro à vérifier | Équipe | Demande depuis « Mon compte » |
| Cadeau de bienvenue en rupture | Équipe | FR-025 |
